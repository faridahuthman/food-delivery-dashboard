# 🚴 Food Delivery Route Analysis

## 📌 Project Overview

This project analyses food delivery performance data using Microsoft Excel to understand delivery efficiency, route performance, and factors affecting on-time delivery.

The analysis was presented through an interactive Excel dashboard using PivotTables, slicers, timelines, and key performance indicators (KPIs).

## 🎯 Project Objectives

* Evaluate overall delivery performance.
* Analyse average delivery time and delivery speed.
* Examine the relationship between delivery distance and delivery time.
* Measure the percentage of orders delivered on time.
* Identify factors contributing to delivery delays.
* Provide data-driven recommendations for improving delivery efficiency.

## 📊 Key Insights

### 1. Average Delivery Time

The average delivery time was **44.7 minutes**, which is just within the 45-minute target.

### 2. On-Time Delivery

Only **51% of orders** were delivered on time, indicating that there is significant room for improvement in delivery performance.

### 3. Distance & Delivery Time

Delivery distance had a strong relationship with delivery time.

* Deliveries below **2 km** averaged approximately **8 minutes**.
* Deliveries of **10 km or more** averaged approximately **74 minutes**.

This suggests that longer delivery distances are an important contributor to delays.

## 💡 Recommendations

### Improve Route Planning

Use more efficient routes and real-time traffic information to reduce unnecessary travel time and route delays.

### Prioritize Long-Distance Orders

Long-distance deliveries should be identified early and assigned appropriate delivery resources to reduce the likelihood of late deliveries.

### Monitor On-Time Performance

Track the percentage of on-time deliveries regularly and investigate recurring causes of delays.

### Consider Delivery Zones

Creating strategic delivery zones or assigning riders based on location could help reduce travel distance and improve overall delivery efficiency.
